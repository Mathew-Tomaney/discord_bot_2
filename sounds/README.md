# Your soundboard clips

Drop audio files in this folder and they show up in `/sfx play` (autocomplete included).
Use `/sfx reload` if the bot is already running, or just wait ten seconds.

- Formats: mp3, ogg, opus, wav, flac, m4a, aac, webm
- The file name becomes the command name: `Dragon Roar.mp3` -> `/sfx play dragon-roar`
- Clips are cut at 90 seconds. For long ambience, queue it as music with `/play` and `/loop track` instead.

## Free places to get good fantasy / sci-fi effects

All of these have CC0 (public domain) or similarly permissive clips:

- https://freesound.org — filter by licence "Creative Commons 0"
- https://pixabay.com/sound-effects/
- https://opengameart.org/art-search-advanced?field_art_type_tid%5B%5D=13
- https://sonniss.com/gameaudiogdc — huge yearly royalty-free bundles

A starter set of synthesised clips (thunder, sword-clash, laser, magic-sparkle, heartbeat, dice-roll, ...)
lives in `sounds-builtin/` and is generated by `npm run sfx` (needs ffmpeg) or automatically in Docker.
